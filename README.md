
# Random Password Generator (Генератор случайных паролей)

Графическое приложение (GUI) на Python для генерации безопасных случайных паролей с возможностью кастомизации и сохранения истории.

## Описание проекта
Приложение разработано на языке Python с использованием стандартной графической библиотеки **Tkinter** и встроенного модуля **random** для обеспечения случайности генерации. Программа позволяет гибко настраивать параметры создаваемых паролей под любые требования безопасности.

### Основные возможности и функции:
* **Настройка длины**: Удобный ползунок (Scale) для выбора длины пароля от 4 до 32 символов.
* **Кастомизация состава**: Чекбоксы для включения/выключения цифр (0-9), букв (a-z, A-Z) и специальных знаков (!@#...).
* **Валидация данных**: Встроенная проверка корректности ввода (защита от генерации пустого пароля).
* **История генераций**: Автоматическая запись всех созданных паролей в локальный файл `password_history.json`.
* **Автозагрузка**: При каждом новом запуске приложение считывает JSON-файл и восстанавливает таблицу истории (Treeview) на экране.

## Примеры использования и тест-кейсы

Вы можете проверить работу программы с помощью следующих сценариев:

1. **Тест №1: Создание простого пароля**
   * *Настройка*: Длина = `8`, включены `Цифры (0-9)` и `Буквы (a-z)`.
   * *Результат*: В поле вывода появится комбинация вида `x7m2k9p4`, а в таблице истории снизу появится новая строка под номером 1.

2. **Тест №2: Создание сложного пароля**
   * *Настройка*: Длина = `16`, включены `Цифры`, `Буквы` и `Спецсимволы`.
   * *Результат*: Программа сгенерирует криптостойкий пароль вида `q#9$zK2!pA8_mR%7`, который также мгновенно запишется в JSON-историю.

3. **Тест №3: Проверка защиты от ошибок (Валидация)**
   * *Настройка*: Отключите все три чекбокса (уберите галочки с цифр, букв и спецсимволов) и нажмите кнопку "Сгенерировать".
   * *Результат*: Приложение не закроется с ошибкой. На экране появится предупреждающее окно: *"Выберите хотя бы один тип символов!"*.

## Инструкция по запуску
Программа использует только стандартные библиотеки Python, поэтому установка дополнительных пакетов не требуется.

Запустите скрипт через терминал:
```bash
python main.py
```
